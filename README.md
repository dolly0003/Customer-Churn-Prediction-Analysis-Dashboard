# Customer Churn Prediction Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing customer churn and identifying the key factors that influence customers to leave a business.
The project combines **Python, Machine Learning, and Power BI** to analyze customer behavior, predict churn, and generate meaningful business insights.

## 🎯 Business Problem

Customer churn can negatively impact business revenue and customer retention.
The main goal of this project is to understand:

* Which customers are more likely to churn?
* What factors are associated with customer churn?
* Which customer segments have higher churn?
* How can businesses improve customer retention?

## 🎯 Project Objectives

* Analyze customer churn patterns.
* Identify important factors affecting churn.
* Build machine learning models to predict customer churn.
* Create an interactive Power BI dashboard.
* Generate actionable business insights and recommendations.

## 🛠️ Tools & Technologies

* **Python** – Data analysis and preprocessing
* **Pandas & NumPy** – Data manipulation
* **Matplotlib & Seaborn** – Data visualization
* **Scikit-learn** – Machine learning
* **Decision Tree** – Churn prediction
* **Random Forest** – Churn prediction
* **Power BI** – Interactive dashboard and business visualization

## 🔍 Project Workflow

1. Data Collection
2. Data Cleaning & Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Analysis
5. Machine Learning Model Building
6. Churn Prediction
7. Power BI Dashboard Development
8. Business Insights & Recommendations

## 🤖 Machine Learning Models

### Decision Tree
A Decision Tree was used to understand the relationship between customer characteristics and churn.

### Random Forest
Random Forest was used as an ensemble machine learning model to improve the reliability of churn predictions by combining multiple decision trees.

## 📊 Power BI Dashboard
The Power BI dashboard provides an interactive view of customer churn, customer segments, and important churn-related patterns.

## 💡 Key Insights

The analysis helps identify customer segments and characteristics associated with higher churn.
These insights can help businesses focus their retention efforts on customers who are more likely to leave.

## 📈 Business Recommendations

* Identify high-risk customers early.
* Focus retention strategies on high-churn segments.
* Monitor customer behavior and engagement.
* Use data-driven insights to improve customer retention.
* Regularly track churn rate and customer segments.
